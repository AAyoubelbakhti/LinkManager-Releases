# LinkManager

Gestor de enlaces multiplataforma. Guarda, organiza y sincroniza tus enlaces entre Android, Windows y la web.

## Descargas

Ve a **[Releases](../../releases/latest)** y descarga la última versión:

| Plataforma | Archivo |
|------------|---------|
| Android | `LinkManager-android-release.apk` (mín. Android 8.0) |
| Windows | `LinkManager-win-Setup.exe` (instala y se actualiza solo) |

## Web

Úsalo directamente desde el navegador en **[lm.aelbak.dev](https://lm.aelbak.dev)**.
